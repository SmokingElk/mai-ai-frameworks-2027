Исследование пяти классических алгоритмов машинного обучения на двух датасетах
(классификация и регрессия): бейзлайн из sklearn, улучшение бейзлайна через
проверку гипотез, собственная имплементация каждого алгоритма на numpy.

## Датасеты

| Задача | Датасет | Размер | Целевая |
|---|---|---|---|
| Классификация | [Maternal Health Risk (UCI 863)](https://archive.ics.uci.edu/dataset/863/maternal+health+risk) | 1014 x 7 | RiskLevel (low/mid/high) |
| Регрессия | [CO2 Emission by Vehicles (Kaggle)](https://www.kaggle.com/datasets/debajyotipodder/co2-emission-by-vehicles) | 7385 x 12 | CO2 Emissions(g/km) |

Оба датасета - реальные практические задачи: медицинский триаж беременных
(IoT-мониторинг, Бангладеш) и прогноз выбросов CO2 автомобилей по
характеристикам (данные Правительства Канады).

## Структура репозитория

```
data/                          # датасеты (csv)
src/                           # собственные имплементации алгоритмов на numpy
  knn.py                       # KNN (классификация и регрессия)
  linear.py                    # логистическая (GD) и линейная (норм. уравнение/GD)
  tree.py                      # решающее дерево (CART: gini / MSE)
  forest.py                    # случайный лес (бэггинг на своих деревьях)
  boosting.py                  # градиентный бустинг на своих деревьях
notebooks/
  lab1_knn.ipynb               # KNN + обоснование датасетов и метрик (п.1)
  lab2_linear_logistic.ipynb   # логистическая + линейная регрессия
  lab3_decision_tree.ipynb     # решающее дерево
  lab4_random_forest.ipynb     # случайный лес
  lab5_gradient_boosting.ipynb # градиентный бустинг + итоги
  summary.ipynb                # сводное сравнение всех алгоритмов
results/                       # метрики всех лаб (json), пишет summary.ipynb
requirements.txt
```

В каждой лабораторной: бейзлайн sklearn (п.2) -> гипотезы и их проверка ->
улучшенный бейзлайн (п.3) -> собственная имплементация на numpy, сравнение
с п.2 и с п.3 (п.4). К каждой ячейке с кодом - комментарий.

## Итоговые результаты

Протокол: фиксированный сплит train/test 80/20 (random_state=42), все
улучшения применяются только к обучающей части, сравнение на одном тесте.

Классификация (лучший вариант каждого алгоритма):

| Алгоритм | Accuracy | macro-F1 | ROC-AUC |
|---|---|---|---|
| KNN | 0.857 | 0.865 | 0.960 |
| Logistic regression | 0.680 | 0.692 | 0.840 |
| Decision tree | 0.847 | 0.856 | 0.926 |
| Random forest | 0.862 | 0.870 | 0.965 |
| Gradient boosting | 0.857 | 0.863 | 0.967 |

Регрессия (лучший вариант каждого алгоритма):

| Алгоритм | RMSE | MAE | R2 |
|---|---|---|---|
| KNN | 6.09 | 2.33 | 0.989 |
| Linear regression | 5.09 | 3.07 | 0.992 |
| Decision tree | 3.56 | 2.05 | 0.996 |
| Random forest | 3.33 | 1.74 | 0.997 |
| Gradient boosting | 3.40 | 1.97 | 0.997 |

Главные выводы (подробно - в summary.ipynb):

- классификация: KNN, лес и настроенный бустинг дают ~0.86 accuracy; данные
  хорошо описываются локальной структурой ("похожие пациенты - похожий риск");
- регрессия: выигрывают ансамбли (лес 3.33, бустинг 3.40); связь почти линейная;
- предобработка зависит от алгоритма: масштабирование критично для KNN и
  градиентных методов и бесполезно деревьям; one-hot помогает всем, кроме KNN;
- чувствительность к гиперпараметрам: бустинг и KNN - высокая, лес - низкая;
- собственные имплементации на numpy во всех лабах воспроизвели sklearn.
